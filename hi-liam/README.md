# Hi Liam

A tiny web app: push the button and it says **"Hi Liam!"**

## How to run

Open `index.html` in any web browser (double-click the file). No installs needed.

## How it works

- `<button>` is the button you push.
- `<p id="message">` is where the greeting appears.
- The JavaScript at the bottom listens for a click and sets the message text to "Hi Liam!".
