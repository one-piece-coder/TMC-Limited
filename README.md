## Paint Store Goal Tracker

`goal-tracker/index.html` is a single-file tracker for sales ($) and gallons. It shows budget vs. actual vs. forecast by day, week, month, quarter and year. To use it, open the file in any browser. It needs no install or internet connection, and your data saves automatically in that browser. Use **Settings & Data → Download backup** to keep a copy or move to another computer.
